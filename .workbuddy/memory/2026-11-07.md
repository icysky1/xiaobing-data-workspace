## 客户端源码定案：1.5 与计算链（game.js 484万字节逐段定位）
- **×1.5 只在行汇总出现，绝不进单位战力**：结算三排 `getFrontBattle`=Math.round(1.5×Σ前排 data.attack/skill_attack)；阵容面板 `caculateFrontBattleNum`=Math.round(1.5×Σ heroBattleNum.attack[1])（含神兽贡献）。中排=Σ(武力+智力)、后排=Σ智力，均不乘。
- **面板/进场值全链**（FormationHero.caculateBattleNum，@2154773）：底数 heroRecord.force → ①羁绊 caculaterFetterStrongNum（固定值+百分比全部加算，且百分比以原始底数为基准）→ ②强化 caculateStronggerBattleNum ×(1+level/1000+stage/1000) → ③阵营 eraAddition ×(1+‰) 乘算单层 → ④科技 → ⑤神器 → ⑥官职（固定+百分比基于当前值加算）→ ⑦称号 lvTitles 行/全体百分比乘算 → round。无 1.5。
- **神兽继承口径（FormationPetData）**：继承池=同排英雄的 caulatePetInheritBattleNum = 仅羁绊+强化后的武力/智力（**不含阵营/科技/神器/官职/称号**），×petInherit‰ 加进神兽底数，之后神兽整体再过阵营乘算等层。→ 模拟器现口径（继承终局值）需改为「羁绊+强化后」。
- **战报播放顺序**（服务端 flow，客户端逐阶段回放）：preparePower 进场 → resetPower 重置技能 → skillBook 兵书 → skillPower 普通技能(0..19 阶段) → **eraSkillPower 阵营技能(0..19 阶段，在军师技之前!)** → gatherPower 助战（=(三排和)×(groupAddationBasics+assistPersent)/1000）→ adviser 军师技 → finalPower。
